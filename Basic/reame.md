# Readme
- [Basic](Basic/readme.md)
This directory contains basic Java programs organized sequentially from 01 to practice core concepts. Each file demonstrates fundamental Java programming techniques. To get the most out of these examples:

1. Remove the numbering prefix from filenames before compiling
2. Execute each program individually to understand its functionality
3. Modify and experiment with the code to reinforce learning

The sequential numbering is for organizational purposes only and helps in systematic review of concepts.
